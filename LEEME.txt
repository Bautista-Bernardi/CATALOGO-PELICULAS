EJECUTAR PYTHON
1. Abrir la carpeta completa en Visual Studio Code.
2. Abrir el archivo programa1_generos.py o programa2_peliculas.py.
3. Presionar Run Python File (triangulo arriba a la derecha).
4. Para consultas, ejecutar programa3_consulta_generos.py o
   programa4_consulta_peliculas.py.
No ejecutar los archivos funciones_*.py directamente: son modulos auxiliares.

EJECUTAR LA PAGINA WEB
1. Instalar la extension Live Server en VS Code.
2. Abrir index.html.
3. Clic derecho y elegir Open with Live Server.
4. Se abrira el catalogo en el navegador.

FILTROS
- El buscador filtra por nombre cuando se escriben al menos 3 caracteres.
- El selector permite filtrar por genero.
- Solo se muestran peliculas y generos activos (baja = 0).

BAJA LOGICA
Los registros no se borran fisicamente. baja = 1 significa inactivo y
baja = 0 significa activo.
